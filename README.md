# MoneyFlow (Equatorial Guinea)

Modern mobile personal finance app built with Expo + React Native + TypeScript.

## Phase status

- ✅ Phase 1: Project scaffold + dependencies + folder structure
- ✅ Phase 2: Bottom tab navigation (Home, Transactions, Goals, AI Coach, Settings)

## Run locally

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start app:
   ```bash
   npm run start
   ```

## Planned stack

- React Native + Expo
- TypeScript
- Supabase backend
- Zustand state management
- Expo Router / React Navigation
- NativeWind (Tailwind)
- Charts with Victory Native
